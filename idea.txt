You are a senior full-stack engineer and UI/UX designer. Build a complete, production-quality web platform for the project:

"IoT-BASED CARBON CAPTURE AND RECOVERY SYSTEM USING MICROALGAE"

──────────────────────────────────────────
1. PROJECT OVERVIEW
──────────────────────────────────────────
A microalgae photobioreactor captures CO₂ through photosynthesis. An ESP32 monitors the culture environment and controls a pump. The website is the monitoring, control, analytics and AI layer. The aim is to maximise algae growth and estimate how much CO₂ is being captured and recovered.

──────────────────────────────────────────
2. HARDWARE (must all be represented in the UI and data model)
──────────────────────────────────────────
Microcontroller: ESP32 (12-bit ADC, 0–4095, 3.3 V reference)

Sensors / actuators:
- DHT11 (GPIO 4): temperature (°C) and humidity (%)
- LDR (GPIO 34): raw ADC value 0–4095, classified as
    DARK (<=300), LOW (<=1000), MEDIUM (<=2200), BRIGHT (>2200)
- pH sensor (GPIO 32): raw ADC (0–4095) and voltage (raw/4095 × 3.3 V).
    Readings are currently RAW and uncalibrated, so build a calibration feature
    (two- or three-point calibration with pH 4.0 / 7.0 / 10.0 buffers) that converts voltage to real pH.
- Water level sensor (GPIO 27, INPUT_PULLUP): digital, HIGH or LOW
- Relay module (GPIO 25, ACTIVE LOW) controlling the water/air pump: ON or OFF
- LCD (currently disconnected): include an optional "LCD status" indicator

The sensors are read every 2 seconds in the current sketch.

──────────────────────────────────────────
4. FIREBASE DATA STRUCTURE
──────────────────────────────────────────
Realtime DB:
/devices/{deviceId}/live: { temperature, humidity, ldrValue, lightLevel, phRaw, phVoltage, phCalibrated,
                            waterLevel, relayStatus, timestamp, online }
/devices/{deviceId}/control: { relayCommand: "ON|OFF|AUTO", mode: "manual|auto|ai", updatedBy }

Firestore:
/readings/{deviceId}/data/{autoId}: all sensor fields + timestamp (written every N seconds)
/alerts/{id}: { type, severity, message, timestamp, resolved }
/calibration/{deviceId}: { phPoints, slope, offset, updatedAt }
/aiInsights/{id}: { summary, recommendations, createdAt }
/users/{uid}: { name, role, preferences }

Provide Firebase security rules (authenticated read/write, device-scoped write for the ESP32).

6. ADVANCED AI FEATURES (modern, LLM and ML based)

5. Smart autonomous pump control: AI decides when to turn the pump ON/OFF based on predictions, with a human override and a decision explanation ("Pump turned ON because pH rose above 8.2 and water is LOW").
6. Daily/weekly AI report generator: automatically written insights and recommendations, exportable as PDF.
7. Optimisation recommendations: ideal light exposure, best operating windows, efficiency score.
8. Voice assistant: ask questions and give commands by voice (Web Speech API).
9. Predictive maintenance: detect sensor drift, pH probe ageing, and needed calibration.
10. Sustainability and carbon credit dashboard: convert captured CO₂ into equivalents (trees planted, car km offset) and an estimated carbon credit value.
11. Digital twin / what-if simulator: sliders for light, temperature and pH showing the predicted effect on growth and capture.
12. Image analysis (optional): upload photos of the culture to estimate density and colour health with a vision model.
